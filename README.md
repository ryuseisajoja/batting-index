# 打席台帳 — 関西・中部・北陸・信越 バッティングセンター229軒

16府県229軒のバッティングセンターを、料金・球速・設備つきで一覧できる台帳兼検索ツール。

## 機能

- **1球あたりの単価で並び替え** — 1ゲームの額ではなく単価で比較できる
- **現在地から近い順** — 位置情報を許可すると距離順に並び替え（市区町村役場の座標ベースの概算）
- **キーワード検索** — 店名・市区町村・特徴を横断
- **重視ポイントで絞り込み** — 安さ / 硬式 / 打ち放題 / 屋内・全天候 / 速い球 / 映像マシン / 他の遊びも
- **県別インデックス** — 軒数・平均単価・県内最安を一覧
- **訪問記録** — 星評価・料金・所感を書き込み、JSONで書き出し／読み込み
- **Googleマップ連携** — 各店から地図アプリを直接起動

JavaScriptを切っていても、一覧表示・絞り込み・並び替え・訪問チェックはCSSだけで動作します。

## 公開のしかた（GitHub Pages）

1. このリポジトリを GitHub に push
2. Settings → Pages → Source を `main` ブランチの `/ (root)` に設定
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開

`index.html` 1ファイルで完結しているので、ビルドは不要です。

## データについて

- 料金・営業状況は**2026年8月時点**の公開情報にもとづく参考値
- 出典：各店公式サイト、[バッセンナビ](https://www.battingcenter.com/)、[開店閉店.com](https://kaiten-heiten.com/) ほか
- 座標は[国土地理院 住所検索API](https://msearch.gsi.go.jp/)の市区町村代表点
- 「要確認」表示の店は料金改定・閉店の可能性あり
- 各店の写真は著作物のため掲載していません
