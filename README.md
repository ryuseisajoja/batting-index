# 打席台帳 — 関西・中部・北陸・信越 バッティングセンター229軒

16府県229軒のバッティングセンターを、料金・球速・設備つきで一覧できる台帳兼検索ツール。

## 機能

- **1球あたりの単価で並び替え** — 1ゲームの額ではなく単価で比較できる
- **現在地から近い順** — 位置情報を許可すると距離順に並び替え（市区町村役場の座標ベースの概算）
- **キーワード検索** — 店名・市区町村・特徴を横断。スペース区切りでAND検索でき、ひらがな・半角カナ・全角英数の違いも吸収する（`愛知 硬式`／`ばってぃんぐ`／`ＵＰ` すべてヒット）
- **重視ポイントで絞り込み** — 安さ / 硬式 / 打ち放題 / 屋内・全天候 / 速い球 / 映像マシン / 他の遊びも / 駅から近い
- **条件の掛け合わせ** — 地域も重視ポイントも複数えらべる（枠内はOR、枠をまたぐとAND）。該当件数と選択中の条件が常に表示される
- **絞り込む前に件数が見える** — 各チップに、いま選んでいる他の条件と掛け合わせた場合のヒット数が出る。0件の条件は薄く表示される
- **単価の上限で絞る** — 8／10／12／15円/球以下。単価が出せない時間制・貸切の店は外れる
- **県別インデックス** — 軒数・平均単価・県内最安を一覧
- **訪問記録** — 星評価・料金・所感を書き込むと、この端末に自動保存される（localStorage）。JSONで書き出し／読み込みも可能
- **まとめて記録** — 表示中の店を一括で訪問済にしたり、記録をまとめて消したりできる
- **記録の一覧** — つけた記録だけを集めて表示。料金の合計と平均評価も出る
- **「要確認」の消し込み** — 料金改定・閉店の可能性がある店（6軒）だけを抽出し、確認した店に日付を刻んで一覧から外していける
- **Googleマップ連携** — 各店から地図アプリを直接起動

JavaScriptを切った場合は全229軒の一覧表示のみになります（検索・絞り込み・訪問記録には JavaScript が必要です）。

訪問記録はブラウザの保存領域に置かれるだけなので、履歴を消したり機種を変えたりすると失われます。残したい記録は「記録を書き出す」でJSONを保存してください。

## 公開のしかた（GitHub Pages）

1. このリポジトリを GitHub に push
2. Settings → Pages → Source を `main` ブランチの `/ (root)` に設定
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開

`index.html` 1ファイルで完結しているので、ビルドは不要です。

## データについて

- 料金・営業状況は**2026年8月時点**の公開情報にもとづく参考値
- 出典：各店公式サイト、[バッセンナビ](https://www.battingcenter.com/)、[開店閉店.com](https://kaiten-heiten.com/) ほか
- 座標は[国土地理院 住所検索API](https://msearch.gsi.go.jp/)の市区町村代表点
- 「要確認」表示の店は料金改定・閉店の可能性あり
- 各店の写真は著作物のため掲載していません

## ライセンス

データの正確性は保証しません。訪問前に各店の公式情報をご確認ください。
